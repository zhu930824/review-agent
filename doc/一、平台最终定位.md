# 1. Review Center

------

# 2. Pre-PR Gate（最关键）

这是平台真正的“质量闸门”。

核心理念：

> AI Coding 不可避免。
>
> 所以必须在 merge 前建立 AI Gate。

能力：

```
提交代码
   ↓
AI Rule Scan
   ↓
Architecture Check
   ↓
Security Scan
   ↓
Multi-Agent Review
   ↓
Judge Model Decision
   ↓
Human Confirmation
   ↓
CI Gate Result
```

Gate 等级：

| 等级    | 含义     |
| ------- | -------- |
| BLOCKER | 阻断     |
| MAJOR   | 人工确认 |
| MINOR   | 建议     |
| INFO    | 提示     |

对应你们 SOP。

------

# 3. Rule Governance Center

这是平台未来的核心资产。

因为：

> AI Coding 最大的问题不是生成代码。
>
> 而是：
>
> “组织经验无法沉淀”。

所以规则中心必须存在。

规则类型：

| 类型              | 示例                                  |
| ----------------- | ------------------------------------- |
| Architecture Rule | 禁止 Controller 调 DB                 |
| DDD Rule          | Application 不允许依赖 Infrastructure |
| Performance Rule  | 禁止循环查库                          |
| Security Rule     | 禁止明文 AK/SK                        |
| Team SOP          | 发布必须双 Review                     |
| AI Rule           | Always Prompt                         |
| Review Strategy   | 多模型组合                            |
| Workflow Template | 发布流程                              |
